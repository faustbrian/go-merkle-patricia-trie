# Merkle Patricia trie specification decisions

This register is the human and machine-auditable boundary for the package's
Ethereum MPT, RLP, profile, proof, and storage choices. Immutable sources and
monitored update channels are pinned in
[monitoring.json](../specification/monitoring.json), and the executable map is
in [conformance.json](../specification/conformance.json).

The key words "MUST", "MUST NOT", "REQUIRED", "SHALL", "SHALL NOT",
"SHOULD", "SHOULD NOT", "RECOMMENDED", "NOT RECOMMENDED", "MAY", and
"OPTIONAL" in this document are to be interpreted as described in BCP 14
[RFC2119] [RFC8174] when, and only when, they appear in all capitals, as
shown here.

Pinned normative text outranks fixtures and peers. Official fixtures establish
only covered examples. Maintained-peer differentials establish only named
interoperability cases and never a general compliance claim. Source movement
requires review and never changes runtime behavior automatically.
